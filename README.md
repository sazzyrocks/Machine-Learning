# Machine Learning Coursework & Hands-On Labs

This repository contains hands-on lab notebooks and assignments covering foundational to advanced concepts in Machine Learning and Data Science.

## 📚 Topics & Notebooks Overview

### Foundations & Data Analysis
- **NumPy & Image Analysis**: Multi-dimensional arrays, matrix operations, and array-to-image manipulation (`NumPy_HandsOn_Array_to_Image_Analysis_Student_Lab_v2_(2) (2).ipynb`)
- **Pandas**: Data manipulation, filtering, aggregation, and data exploration (`Pandas_HandsOn_Student_Lab (2).ipynb`)
- **Statistics & EDA**: Exploratory Data Analysis, summary statistics, correlation, and distribution analysis (`Statistics_EDA_HandsOn_Student_Lab (2).ipynb`)
- **Data Preprocessing**: Handling missing values, categorical encoding, scaling, and feature transformation (`Preprocessing_HandsOn_Student_Lab (1).ipynb`)

### Supervised Learning
- **Linear & Polynomial Regression**:
  - Foundations & Teaching Notebook (`Linear_Poly_Regression_Teaching_Notebook_.ipynb`)
  - Week 5: Linear Regression Lab (`Week5_Linear_Regression_Student_Lab (2).ipynb`)
  - Week 6: Polynomial Regression & Regularization (Ridge / Lasso) (`Week6_Polynomial_Regularization_Student_Lab (2).ipynb`)
- **K-Nearest Neighbors (KNN)**: Distance metrics, classification & decision boundaries (`Week7_KNN_Distance_Measures_Student_Lab_(1).ipynb`)
- **Decision Trees**: Tree-based classification, splitting criteria (Gini, Entropy), and pruning (`Week8_Decision_Tree_Student_Lab (1).ipynb`)
- **Naive Bayes**: Probabilistic classification, Bayes' Theorem, and text/feature classification (`Week10_NaiveBayes_Student_Lab.ipynb`)

### Unsupervised & Specialized Learning
- **Principal Component Analysis (PCA)**: Dimensionality reduction, covariance matrices, and explained variance (`Week9_PCA_Student_Lab.ipynb`)
- **Recommendation Systems**: Collaborative filtering, matrix factorization, and similarity scoring (`Week10_Recommendation_Systems_Student_Lab (1).ipynb`)
